## Implemented in this programming pass

- Real owner request dashboard with saved customer/contact/date/fulfillment, fixed product or complete bouquet contents, original price, private notes, pagination/status counts and download of the recorded design details. Owner history remains available after subscription expiry. Administrator inspection is read-only.
- Requested → accepted → fulfilled/cancelled lifecycle with independent optimistic versions, terminal-state protection, stale edit handling and escaped customer text. Fulfillment changes never mark a request paid. Status counters are constant-size and transactionally updated; legacy rows hydrate without destructive rewriting.
- Authoritative saved-draft publication report with actionable missing prices, disabled bouquet choices, empty designs, products and activation gates. Content readiness is distinct from subscription activation and customer payments. Square remains optional for publication.
- Actual Order action now opens contents/estimate review. Customise opens the same design for editing. Owner review cannot submit; public review submits only an unpaid request. The new browser includes the reviewed published version so repricing requires reloading; duplicate retries retain their original receipt.
- Explicit Use design as photo action renders/compresses the saved design and uploads immutable cover media. No florist photo is replaced automatically. Stale designs/versions cannot silently replace a newer cover.
- Catalogue grouping and explicit turn-off-unpriced action, preserving all saved prices and artwork. Generic note pricing is stated in shop currency; unsupported imported cash-supply/deposit terms are blocked from public quotes instead of ignored. Ray's original pricing remains separate and unchanged.
- Sandbox Square connection routes, encrypted per-shop SQLite tokens, unique merchant registry, browser-bound one-use OAuth callback, supported location selection, refresh/revoke and owner management UI. No real provider account was connected. Sandbox configuration remains disabled; production connection and customer checkout are rejected. See SQUARE-CONNECTION.md.
- Responsive request detail appears before the bounded scrolling list on phones. Sign-in/registration copy accurately states that this is an invited private beta.

## Release gates retained

Public merchant admission, publication, subscriptions, Square sandbox connection and customer card checkout remain disabled in the deployed private beta. No paid plan, provider secret, payment, email or real merchant authorization was created in this pass. Existing apex/Ray sites remain separate.

The user's own payout-method research is intentionally deferred until they choose to resume it. This release does not claim that live financial integration is complete: subscription webhook/entitlement reconciliation, generic customer-checkout ledger, merchant-approved commerce rules and real provider Sandbox acceptance remain required before live payment.
