# Motion storyboard

This is a local creative preview, not a finished ad. It uses an actual builder export (`builder/tests/halloween/forever-my-boo.png`) as a storyboard still. It does not simulate flower replacement, stock checking, a sent message or a fulfilled customer order.

Run `npm run dev` in this folder. Studio is currently at http://localhost:3000 . The preview server can be stopped with Ctrl+C in its terminal.

Compositions:

- `A-MoreRed`: immediate customer-color question.
- `B-PriceQuestion`: price-in-DMs hook, closest to the September evidence.
- `C-FinalSay`: florist creative-control hook.

All are 1080 × 1920, 30 fps, 20 seconds, with the same body/offer/CTA. Separate scene compositions are available for timing work. Preview annotations and placeholder stills must be removed/replaced when the real recording arrives. The scene instructions identify each missing shot. No final MP4 has been exported.

The exact script, optional voiceover, current offer and recording checklist are in `../HALLOWEEN-AD-V2-2026-10-11.md`.

The runtime was scaffolded with the official Remotion tool using the installed official skill. Product implementation was not changed. Canva v1 designs were left intact. Lint and TypeScript validation passed; final creative timing and phone readability still require the supplied footage.
