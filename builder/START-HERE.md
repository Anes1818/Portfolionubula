# ابدأ هنا — Nebula v6

1. فك ضغط الملف كاملًا داخل مجلد جديد، ثم افتح **index.html** على الكمبيوتر. لا حاجة إلى npm أو بناء المشروع.
2. للهاتف: ارفع المجلد كاملًا إلى استضافة موقع ثابت وافتح رابط الموقع. معاينة ملف HTML داخل تطبيق Files ليست تجربة الموقع الكاملة.
3. قبل استعماله مع الزبائن، اضبط **shop-config.js** وفق **SHOP-SETUP.md**. الأسعار الحالية تجريبية بالدولار، ولا يوجد رقم متجر أو بريد متجر مفترض.

## طريقة الاستعمال
- **Classic** يبدأ افتراضيًا. القبة والقلب باقتان مستقلتان ومحفوظتان أيضًا.
- **Dome / Auto blend:** اختر الأنواع مباشرة، أو افتح أنماط المزج والأزهار المميزة.
- **Paint by hand:** اختر الزهرة ثم اضغط أو اسحب على الخانات. لا توجد نافذة Replace.
- للحذف: أنهِ الرسم، اضغط على زهرة ثم اضغط ×. في القبة والقلب تبقى خانتها فارغة ويمكن إعادة ملئها.
- تغيير الحجم يطلب تأكيدًا مع التقدير الجديد. يعاد تطبيق المزج أو مناطق القلب، وتحفظ التعديلات اليدوية حيث يمكن.
- كبّر المعاينة واستعمل التكبير والتحريك للقوالب الكثيفة.
- **Ask florist** ينشئ طلب عرض سعر للباقة الحالية فقط. لا يرسل شيئًا تلقائيًا ولا يؤكد شراءً.
- **Save design** يحفظ الصور وملف JSON قابلًا للتعديل يضم الباقات الثلاث. احتفظ به كنسخة احتياطية.

اقرأ **TEST-REPORT.md** لمعرفة الاختبارات الفعلية وحدودها. لا تعتبر المعاينة أو الأرقام التجريبية تأكيدًا للسعر أو لإمكانية التنفيذ قبل مراجعة محل الزهور.
