# Halloween: nine cutouts for three bouquets

**Archived generation brief.** Seven cutouts have been supplied and integrated.
The final versions reuse the existing round black collar and omit the Jack topper.
No more assets are needed to use these versions. See
[HALLOWEEN-LAYOUT.md](HALLOWEEN-LAYOUT.md) for the implemented logic.

These are component images, not complete bouquets. Generate one file at a time,
then clip the background and export a transparent PNG at the original size.
Keep thin stems, petal tips and the holes between pieces. No white outlines.
Use 1536 pixels or more on the longest edge, sharp detail, soft daylight from
upper left, and a plain light-grey background for clipping. Do not ask the image
model to draw transparency checkerboards. Keep 8–10% margin around the object.

The counts below are proposed builder recipes, not counted reproductions of the
photographs. We will measure the final alpha silhouettes before activating them.
